# KOKKI-FF | Free Fire Nickname Designer

**KOKKI-FF** is a stylish Free Fire nickname generator created by **AB~SQUAD 1521**.  
Users can design unique nicknames with **emojis, symbols, and cool font styles**.  

---

## Features

- Generate nicknames from your own input  
- Generate random nicknames (adjective + noun)  
- Unlimited nickname generation  
- Click-to-copy nicknames with tooltip feedback  
- Random emoji insertion inside nicknames  
- Neon-glow animated style  
- Mobile-friendly and responsive  
- Terms & Privacy pages included  

---

## Usage

1. Enter your name in the input field.  
2. Select the number of nicknames to generate.  
3. Click **Generate Nickname** or **Random Nickname**.  
4. Click on a nickname to copy it to your clipboard.
